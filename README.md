# DS110 Statistics 2 — Interactive Learning Guide

An interactive textbook for AUA DS110 Statistics 2 covering Lecture 3 (regression models) and Lecture 4 (nonparametric statistics), based on lectures by Vahe Movsisyan.

**[Open the guide](https://reneviva.github.io/ds110-statistics2-guide/)**

24 lessons pair manual mathematics with R programming, complete worked examples, rank tables, formula explanations and source discrepancy notes. Includes blue light/dark themes, search, local study progress, copyable R code and editable educational tools.

## Use offline

Download `index.html` and open it in Chrome or Edge. The HTML contains its own CSS, JavaScript, fonts and rendered mathematics; no server or internet is needed. R snippets run in your R installation, not in the browser.

## Coverage and verification

See [COVERAGE_AND_VERIFICATION.md](COVERAGE_AND_VERIFICATION.md) for the 85-page source matrix, numerical and R checks, source discrepancies and verification boundaries.

Original lecture PDFs/screenshots and the missing source CSVs are not included in this repository. Lecture-reported model output is distinguished from new, runnable illustrative datasets. This is a study resource; it is not an official AUA publication.

## Hosting

GitHub Pages serves `index.html` directly from the root of `main`. `.nojekyll` disables unnecessary Jekyll processing. Updating this branch updates the hosted guide.
